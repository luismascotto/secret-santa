# Secret Friend - Number Raffle

A simple static web page for raffling numbers to play "Surprise Secret Santa" with friends.

## Usage

Open `index.html` in your browser. No build process or server required.

1. Set the number of players (1–30)
2. Click "Create Secret Friend" to initialize
3. Click "Next" to draw each number in sequence
4. The app uses cryptographically secure random selection

## Features

- Dark theme interface
- Visual number grid showing remaining options
- Audio feedback during draws
- History tracking of drawn numbers
- No external dependencies
